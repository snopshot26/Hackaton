# DatsSol Python Bot

Готовый бот на Python для DatsSol: ход за ходом получает состояние мира, выбирает действия и отправляет команды.

## Запуск

```bash
export DATSSOL_TOKEN="<ваш_токен>"
python3 datssol_bot.py
```

## Что теперь есть

- 📄 Логи сохраняются в файл (`DATSSOL_LOG_FILE`, по умолчанию `datssol_bot.log`).
- 🖥️ Консольный UI с эмодзи: видно все известные данные по миру, прогнозы, текущий план и отправляемый payload.
- 🧠 На каждом ходу отображается, что бот делает прямо сейчас и почему.

## Переменные окружения

- `DATSSOL_TOKEN` — обязательный токен.
- `DATSSOL_BASE_URL` — базовый URL API (по умолчанию `https://games-test.datsteam.dev`).
- `DATSSOL_ARENA_PATH` — путь arena (по умолчанию `/api/arena`).
- `DATSSOL_COMMAND_PATH` — путь command (по умолчанию `/api/command`).
- `DATSSOL_LOGS_PATH` — путь logs (по умолчанию `/api/logs`).
- `DATSSOL_POLL_INTERVAL` — минимальная задержка между итерациями цикла (по умолчанию `0.15`).
- `DATSSOL_TIMEOUT` — таймаут HTTP-запросов (по умолчанию `5.0`).
- `DATSSOL_DRY_RUN` — `1` для dry-run без отправки команд на сервер.
- `DATSSOL_LOG_FILE` — файл логов (по умолчанию `datssol_bot.log`).
- `DATSSOL_UI_CLEAR` — очищать экран каждый ход (`1`/`0`, по умолчанию `1`).

## Что делает стратегия

1. Покупает апгрейды по приоритету: `repair_power` → `signal_range` → `settlement_limit` → далее защитные/вспомогательные.
2. Чинит просевшие по HP плантации в критической зоне.
3. Строит новые плантации с приоритетом усиленных клеток (`x % 7 == 0 && y % 7 == 0`).
4. Остатком действий атакует вражеские плантации/бобров в радиусе.
5. При изоляции ЦУ пытается перенести его на соседнюю связную плантацию.
6. Никогда не отправляет полностью пустой ход (делает fallback-действие).

## Важно

Это **боевой базовый бот**, который можно запускать сразу. Для топ-результатов имеет смысл донастроить эвристику под живой матчап и мету раундов.
